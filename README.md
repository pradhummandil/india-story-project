# 📖 About

India Story Project is a premium editorial storytelling platform designed to preserve and showcase India's untold stories.

Unlike traditional blogs, the platform focuses on immersive storytelling with cinematic UI, multilingual support, interactive exploration, and a scalable CMS architecture.

The project combines modern frontend technologies with a production-ready backend powered by Supabase and Prisma.

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/pradhummandil/india-story-project.git

cd india-story-project
```

Install Dependencies

```bash
npm install
```

Configure Environment Variables

```env
DATABASE_URL=

DIRECT_URL=

VITE_SUPABASE_URL=

VITE_SUPABASE_ANON_KEY=

SUPABASE_SERVICE_ROLE_KEY=
```

Generate Prisma Client

```bash
npx prisma generate
```

Run Development Server

```bash
npm run dev
```

Production Build

```bash
npm run build
```
